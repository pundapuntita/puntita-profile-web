Q1 Tier Journal Strong Convergence Proven J. Comput. Appl. Math. (2026)

Double Inertial Viscosity Forward-Backward Algorithm for Split Variational Inclusion with Applications to Deblurring of Medical Images and Data Classification

Authors: Puntita Sae-jia, Eakkpop Panyahan, Suthep Suantai, and Jen-Chih Yao
Journal: Journal of Computational and Applied Mathematics, 488, 117823 (2026) • DOI: 10.1016/j.cam.2026.117823

Convex Bilevel Optimization Model
Outer-level:   minx ∈ Γ φ(x)
Inner-level (Constraint Γ):   argminx ∈ H { f(x) + g(x) }

where φ: H → ℝ is a strongly convex and differentiable function with parameter σ > 0 on real Hilbert space H.

Split Variational Inclusion Problem (SVIP)
Find x* ∈ H₁ such that:   0 ∈ (A₁ + B₁)(x*)   and   0 ∈ (A₂ + B₂)(Lx*)
Algorithm 8: Double Inertial Viscosity Forward-Backward Algorithm Strong Convergence Proven
Initialization: Choose x1, x0, x-1 ∈ H, λn ∈ (0, 1 / ‖L‖²), {rn} ⊂ (0, β], and {βn} ⊂ (0, 1). Take {ξn}, {μn} ⊂ (0, ∞) and {ρn} ⊂ (-∞, 0).
Iterative Steps: For n ≥ 1, calculate xn+1 as follows:
Step 1 (Compute Inertial Steps):
θn = min { μn,   ξn / ‖xn - xn-1‖ }   if xn ≠ xn-1;   otherwise   μn
δn = max { ρn,   -ξn / ‖xn-1 - xn-2‖ }   if xn-1 ≠ xn-2;   otherwise   ρn
Step 2 (Compute Double Inertial & Forward-Backward Updates):
wn = xn + θn(xn - xn-1) + δn(xn-1 - xn-2)
yn = JrnA₁, B₁ ( wn - λn L* (I - JrnA₂, B₂) L wn )
zn = JrnA₁, B₁ ( yn - λn L* (I - JrnA₂, B₂) L yn )
xn+1 = βn F(xn) + (1 - βn) zn
Update: Set n := n + 1 and return to Step 1.
Theoretical Convergence Theorem: The sequence {xn} generated by Algorithm 8 is mathematically proven to converge strongly to a solution of the convex bilevel and split variational inclusion problem.
